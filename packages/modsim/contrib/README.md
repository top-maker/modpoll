# Device data moved

The active model contribution source is
[modbus-models](https://github.com/top-maker/modbus-models).
Use its contribution guide and target main. This directory no longer accepts
model edits. Historical commits and published releases are unchanged.

The initial curated data release contains two ADAM models; other former catalog
entries remain historical, pending source/redistribution review. See the
[fixed migration inventory](https://github.com/top-maker/modbus-models/blob/2493526acc6645393b3ebb3f32279167a88d6f41/schemas/migration.yaml).
Prepare current examples using tools/fetch-models.py and examples/model-source.yaml.
