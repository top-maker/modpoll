Installation

This documentation describes the 2.x functional preview. Install the exact version:

uv tool install --prerelease allow 'modpoll[serial]==2.0.0a8'

For existing CSV installations use uv tool install 'modpoll<2' and the 1.x documentation. The preview image is topmaker/modpoll:2.0.0a8; stable latest stays on 1.x. See v1 compatibility and M3 acceptance for tested platforms and hardware limitations.

This program is tested on python 3.10+ (Ubuntu 22.04+ or equivalent). Ubuntu 20.04 and python 3.8 are no longer supported.

Install with uv

The package is available in the Python Package Index,

uv tool install --prerelease allow "modpoll==2.0.0a8"

Optionally, pyserial library can be installed for Modbus-RTU communication,

uv tool install --prerelease allow 'modpoll[serial]==2.0.0a8'

Run the following command to check if there is new version available,

uv tool install --upgrade --prerelease allow "modpoll<3"

Uninstall

The program can be uninstalled by the following command,

uv tool uninstall modpoll

Run with docker

A docker image has been provided for user to directly use the tool without the local installation,

docker run --rm topmaker/modpoll:2.0.0a8

It shows the version of the tool by default.
